# RTL Design and Synthesis Workshop

A week-by-week record of RTL design, simulation, synthesis, and physical-design learning through the VSD workshop.

## Contents

| Week | Topics |
|---|---|
| [Week 1](./Week_1) | RTL design/testbench basics, Icarus Verilog, GTKWave, introductory Yosys synthesis, reset behavior |
| [Week 2](./Week_2) | Logic optimization, GLS, synthesis/simulation mismatch, blocking vs non-blocking, latch inference, generate constructs, RCA |
| [Week 3 — Physical Design (PD)](./Week_3_Physical_Design) | Open-source EDA, OpenLane, RTL-to-GDSII concepts, floorplanning, standard-cell characterization, timing, CTS, routing, DRC |
| [Week 4 — VSDBABYSOC](./Week_4_VSDBABYSOC) | Codespace setup, OpenROAD flow, synthesis, placement, CTS, routing, parasitic extraction, post-route STA, 16-corner analysis, results, lessons, debugging |

## Repository conventions

- Each week contains its own notes and supporting evidence.
- Store screenshots in the relevant week's images directory and embed them near the explanation they support.
- Preserve the provenance of measured values and document limitations.
- Present results and technical learnings before the problems-and-resolutions section.
