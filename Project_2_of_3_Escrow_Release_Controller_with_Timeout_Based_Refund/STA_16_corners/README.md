# Escrow Release Controller — 16-Model SKY130HD STA

## Purpose and status

This folder contains supplementary static-timing analysis for the routed escrow controller. The sweep compares one routed implementation against 16 SKY130HD standard-cell Liberty timing models.

**Current status: preliminary / REVIEW.** The committed baseline contains WNS and hold worst slack, but TNS was not captured. TNS must remain blank until the updated script produces measured values; never replace missing TNS with zero.

## Contents

- `summary.csv` — per-model setup WNS, setup TNS, hold worst slack and status.
- `setup_wns_by_corner.png` — existing WNS graph; regenerated by the report script.
- `setup_tns_by_corner.png` — generated from measured TNS after the sweep.
- `STA_16_Corner_Report.docx` — generated report; regenerate after the sweep.
- `run_sweep.sh` — OpenSTA sweep driver.
- `generate_report.py` — CSV validation, chart and DOCX generator.
- `tns_status.csv` — TNS capture status.

## Run the complete sweep

Run in the Linux/OpenSTA environment containing the matching routed netlist, SDC, SPEF and Liberty models. Set the inputs to files from **one consistent physical-design run**:

```bash
export OPENSTA=${OPENSTA:-sta}
export LIB_DIR="/absolute/path/to/sky130_fd_sc_hd/timing"
export STA_NETLIST="/absolute/path/to/escrow_synth.v"
export STA_SDC="/absolute/path/to/constraints.sdc"
export STA_SPEF="/absolute/path/to/escrow_release_controller.spef"
export STA_DESIGN="escrow_release_controller"
python3 -m pip install -r requirements.txt
chmod +x run_sweep.sh
./run_sweep.sh
```

Optional: set `MACRO_LIBS` to a colon-separated list of additional Liberty files required to link the netlist. Do not include CCS-noise variants. The script expects exactly 16 non-CCS-noise `sky130_fd_sc_hd__*.lib` files and stops if inputs are missing or a corner run fails.

The sweep writes one log per model, extracts setup WNS/TNS and hold worst slack, records `check_setup -verbose` output for constraint review, updates `summary.csv`, then regenerates both graphs and the DOCX. If parsing fails, inspect the OpenSTA log and adjust the parser to your OpenSTA version; no metric should be guessed.

## Methodology and interpretation

1. Load one standard-cell Liberty model and optional macro libraries.
2. Load the netlist, link the design, read SDC and SPEF, then propagate clocks.
3. Report setup (max) WNS and TNS, hold (min) worst slack and `check_setup -verbose` for every model.
4. Compare the 16 models using the same routed SPEF. This is a controlled timing-model comparison, not a per-corner re-route.
5. Review numerical results and constraint-coverage logs. Positive slack only describes paths covered by constraints.

### CCS-noise variants excluded

- `sky130_fd_sc_hd__ff_n40C_1v95_ccsnoise.lib`
- `sky130_fd_sc_hd__ss_n40C_1v60_ccsnoise.lib`

These are model variants, not additional PVT corners.
